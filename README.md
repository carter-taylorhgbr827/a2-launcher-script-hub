## Troubleshooting Guide

### A2 Launcher will not open

Make sure the downloaded build is appropriate for your desktop environment. When running from source, confirm that Python is installed and that the project's required dependencies are available.

### An update or download ends before completion

Try again using a reliable network connection. If the problem persists, download the build manually and launch it from the local machine.

### The installer cannot save to the chosen directory

Select a location your user account can write to, or change the destination during setup. Do not modify existing files until you have checked the current installation.

### Minecraft does not show installed mods or updated skins

Verify that Minecraft is using the same local game setup configured by the launcher. Review the status and diagnostics information, then run the appropriate installation or update action again if needed.

### Status details are missing or incomplete

Exit and reopen A2 Launcher, then revisit the diagnostics view. If the information is still incomplete, save the displayed details before contacting project support.
